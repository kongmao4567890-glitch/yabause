# 按游戏名称添加金手指

入口：游戏菜单 → 金手指 → Local（本地）→ 按游戏名称添加金手指。

输入中文名、英文名或游戏编号，选择对应版本，然后勾选条目并点击
“添加所选”。长按条目可预览代码。添加后的条目在本地列表中启用，
代码始终保存到当前运行游戏的 ID 下；搜索结果的名称或编号不会改变
当前游戏归属。同一游戏内按整组代码去重，批量添加使用数据库事务。

## 资料来源

用户提供的 `SS金手指和秘籍.txt`、`SS金手指和秘籍1.txt`、
`SS金手指和秘籍2.txt`。原文分别保存在
`tools/cheat_catalog_sources/ss-cheats-0.txt`、`ss-cheats-1.txt`、
`ss-cheats-2.txt`，保留原文中的分享者署名和版本信息。

离线库包含 759 个游戏记录（不同版本和来源分别保留），11,765 组
可添加代码和 484 组仅供参考代码。原始资料的游戏效果没有逐款实机验证。

`tools/build_cheat_catalog.py` 生成打包进 APK 的 UTF-8 JSON。
解析时按描述分组，不依赖描述之间存在空行；连续多行和条件码保留
为同一组。`第1关=代码` 之类的选项分别生成独立条目并保留章节说明。
按键秘籍可以在界面中阅读。不完整代码、当前核心不支持的格式，或
以条件码结尾的缺损组不会部分导入，原始代码仍可查看。

当前核心支持 `1`（16 位写入）、`3`（8 位写入）及 `D`（条件）类型。
没有把其他平台的代码或硬件主码自动转换成 Saturn 内存地址。

## 验证

- `python3 tools/test_cheat_catalog.py`：真实资料重建一致性、多行分组、
  独立选关、缺损组、秘籍保留及实际 C 代码解析器的无效输入检查。
- `:app:testDebugUnitTest --tests org.uoyabause.android.cheat.CheatCatalogTest`：
  打包资料加载、中英文/全角数字/编号搜索、译名别名、版本区分及代码校验。
- GitHub Actions 编译 Android APK，并使用现有固定签名核验包名、证书和版本号。

同时修正了本地启用列表重复累积的问题，以及 JNI 将添加失败状态当作
数组索引写入的问题。APK 包名和固定签名配置沿用此前版本。
